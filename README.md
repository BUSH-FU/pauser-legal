# Pauser · Legal

Pauser iOS app 的用户协议与隐私政策,通过 GitHub Pages 公开托管。

## 包含文件

- `index.html` — 入口页(两个文档的卡片)
- `terms.html` — 用户协议(Terms of Service)
- `privacy.html` — 隐私政策(Privacy Policy)
- `assets/style.css` — 文档样式
- `assets/favicon.svg` — 站点图标

## 部署

本仓启用 GitHub Pages,从 `main` 分支 `/` 根目录提供静态文件。

公开 URL:`https://bush-fu.github.io/pauser-legal/`

- 用户协议:`https://bush-fu.github.io/pauser-legal/terms.html`
- 隐私政策:`https://bush-fu.github.io/pauser-legal/privacy.html`

## 关于

- 本仓是<strong>公开</strong>的法律文档仓(任何人都可读),与 Pauser iOS App 源代码仓分开。
- App 源代码为私有仓,本仓不包含任何业务代码或私有信息。
- 内容由开发者维护,反映当前 Pauser 产品的实际数据行为(不收集、可清除、本机存储)。
